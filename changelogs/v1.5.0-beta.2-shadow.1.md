## v1.5.0-beta.2-shadow.1 — 2026-07-14

This Shadow preview rebases the ShadowOB adapter on the latest upstream
cc-connect main branch and fixes direct routing for Codex Buddies.

### Fixed

- Classify Buddy Inbox routes from explicit Shadow remote-config metadata, with
  a topic-based fallback for rolling upgrades.
- Resolve newly created direct-message channels from `kind=dm` even when the DM
  did not exist when cc-connect started.
- Keep DM and Buddy Inbox delivery outside ordinary channel multi-Buddy
  coordination. These routes never call the retired
  `/api/buddy-collaborations/claim` endpoint.
- Reject events for unconfigured ordinary channels instead of dispatching them
  with an empty policy.
- Respect `listen=false` as a hard channel routing boundary.

### Upstream Sync

- Includes upstream cc-connect changes through `72d6fb61`, including Reasonix,
  Matrix, Webex, Cloud Web, WPS Agentspace, Yuanbao, and recent agent/runtime
  reliability fixes.
